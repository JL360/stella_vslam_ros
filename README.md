# stella_vslam_ros

[stella_vslam](https://github.com/stella-cv/stella_vslam)'s ROS package.

## 🔧 ROS 2 Kilted Build Fixes

This fork includes important fixes for building with **ROS 2 Kilted** and newer distributions. If you're experiencing build errors with the original repository, this fork resolves the following issues:

### Issues Fixed

1. **CMake Environment Hook Conflict**
   - **Error**: `CMake Error: Files to be generated by multiple different commands: library_path.dsv`
   - **Fix**: Removed duplicate `ament_environment_hooks()` call that was causing multiple commands to generate the same file

2. **Deprecated Header Includes**
   - **Error**: `fatal error: cv_bridge/cv_bridge.h: No such file or directory`
   - **Fix**: Updated to modern header includes:
     - `cv_bridge/cv_bridge.h` → `cv_bridge/cv_bridge.hpp`
     - `message_filters/subscriber.h` → `message_filters/subscriber.hpp`
     - `message_filters/synchronizer.h` → `message_filters/synchronizer.hpp`
     - `message_filters/sync_policies/*.h` → `message_filters/sync_policies/*.hpp`

### When to Use This Fork

Use this fork if you encounter any of the following with the original repository:

- ✅ Building on **ROS 2 Kilted** or newer distributions
- ✅ CMake errors about "multiple commands generating the same file"
- ✅ Missing `cv_bridge/cv_bridge.h` compilation errors
- ✅ Deprecation warnings about message_filters headers
